
# 📊 Interactive Regional Sales Performance Dashboard

An interactive, macro-enabled Excel analytics workspace designed to evaluate sales executive performance, target achievement percentages, and regional sales distribution across major Indian metropolitan areas.

---

## 🔍 Overview

This project provides an intuitive and dynamic dashboard interface built inside Microsoft Excel. It features automated pivot reporting, macro-driven control toggles, interactive slicers, and dynamic charts to enable seamless data-driven decision-making for sales managers and regional heads.

---

## ✨ Key Features & Functionality

* **🏙️ Multi-City Regional Slicers:** Quick single-click filtering across cities including Chennai, Delhi, Mumbai, Nagpur, Patna, Pune, Ranchi, and Surat.
* **🎛️ Dynamic Dashboard View Toggles:** Macro-controlled checkboxes allowing users to show or hide specific analytical panels in real time.
* **📊 Total Sales Analysis:** Tracks top sales executive totals with corresponding horizontal bar chart visualizations.
* **🎯 Target Hit % Analysis:** Calculates percentage target achievements by executive paired with proportional pie chart breakdowns.
* **📈 Variance & Gap Tracking ("Away From Target"):** Line charts tracking percentage deviation from targets across sales teams to highlight areas needing intervention.
* **⚡ Automation & Custom UI:** Integrated VBA scripts and custom form controls for dynamic layout adjustment.

## 🚀 How to Use

1. **Clone/Download** this repository to your local machine.
2. Open `Regional_sales_target.xlsm` in Microsoft Excel.
3. Ensure **Macros are enabled** when prompted by Excel to allow dynamic panel toggling.
4. Use the **City Slicers** at the top to filter data by region.
5. Use the **Dashboard Checkboxes** (Dashboard 1–4) to toggle individual analysis views on or off.
